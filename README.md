# A. Gowri Devi — Developer Portfolio

A responsive React and Vite portfolio featuring a warm editorial chronicle aesthetic, live skill marquees, interactive project case files and credentials, academic records, a print-ready resume, and a validated contact form.

## Development

```sh
npm install
npm run dev
```

## Validation

```sh
npm run lint
npm run build
```

## Profile content

Candidate information and portfolio entries are maintained in `src/data/portfolioData.js`. Add verified profile, project, and demo URLs there when available; the interface shows a non-link status until a URL is provided.
